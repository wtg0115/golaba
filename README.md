# 골라봄

링크로 넣어 둔 유튜브 영상만 보는 유튜브식 웹앱이에요. 추천 영상 없이, 고른 영상만 나와요.

**바로 쓰기:** https://wtg0115.github.io/golaba/

## 기능
- 유튜브 링크(일반 · youtu.be · 쇼츠 · 라이브)를 붙여넣어 추가, 여러 개도 한 번에
- 직접 만든 플레이어 컨트롤: 영상이 끝나면 유튜브 추천 대신 내 목록의 다음 영상
- 이어 보기, 시청 진행 막대, 두 번 탭해서 10초 이동, 재생 속도, 전체 화면, 키보드 단축키(k · j · l · f · m)
- 앱으로 설치(홈 화면 · 앱 목록), 카카오톡 안에서 열면 브라우저로 여는 안내
- 유튜브식 설정(⚙): 앰비언트 모드, 자동재생, 반복 재생, 수면 타이머, 재생 속도, 자막(언어 · 자동 번역 · 글자 크기), 극장 모드
- 재생목록: 앱 안에서 만들기 · 저장 · 순서 바꾸기, 셔플 · 반복 재생, 유튜버별 자동 묶음
- 유튜브 재생목록 가져오기: 공개 · 일부 공개 재생목록 링크를 붙여넣으면 영상이 순서대로 들어옴 (최대 200개, 다시 불러오기 가능)
- 시청 기록, 설정 페이지(테마 · 자막 기본값 · 백업 코드로 기기 옮기기)

## 알아 둘 점
- 영상과 재생목록은 기기마다 브라우저 안(localStorage)에만 저장돼요. 다른 기기로 옮길 땐 설정 → **백업 코드 복사 / 복원**.
- 파일을 직접 열면(file://) 유튜브가 재생을 막아요. 꼭 웹 주소로 여세요.
- 유튜브가 넣는 광고는 막을 수 없어요.
- 화질은 유튜브가 외부 플레이어에서 바꾸는 기능을 막아 둬서 자동으로만 정해져요.
- 비공개 재생목록, ‘나중에 볼 동영상’, ‘좋아요 표시한 동영상’은 가져올 수 없어요.
